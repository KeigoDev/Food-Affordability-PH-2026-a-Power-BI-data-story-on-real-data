    Stages of the process

    This dashboard and the Power BI report come from the same pipeline. Each stage has its own file in the project.

    1

    Extract

    Python · pandas

    Pulls PSA OpenSTAT and ECB data through their APIs, adds SWS, wage-order and policy figures with source links, and saves one raw Excel workbook.

    2

    Clean

    Power Query (M)

    Unpivots month columns, turns PSA's “.” placeholders into nulls, parses dates, sets types, and joins PSA's two region-naming styles.

    3

    Model

    Star schema

    Fact tables for prices, inflation, FX, GDP and hunger, linked to a Calendar and a Region dimension.

    4

    Calculate

    DAX

    Measures for latest vs year-ago, peso weakening, months above target, kg of rice per wage, regional gaps.

    5

    Visualize

    Power BI report

    Story pages with slicers, cross-highlighting and drill-through, mirrored in this web dashboard.

    6

    Validate & share

    Python checks

    Checks that every DAX column and measure exists, compares cards with expected values, then shares the .pbix.
